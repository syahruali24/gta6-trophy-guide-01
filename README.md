Open app/index.html in desktop Chrome. The guide works offline, and the checklist saves in the current browser. Export a JSON backup before moving to another browser or device. Import replaces the current checklist with the backup.

Start with the roadmap and review the six precaution flags during story play. The spoiler shield starts on and hides unearned story entries. Guides cite the official trophy requirements; unknown triggers and lockout windows are identified where relevant.

With Node 22 or later, run `MAKEFUN_OUTPUT_DIR=out node main.ts` to build the offline package. Run `node scripts/check.mjs` with the unpacked competition kit next to the app. With Chrome listening on port 9222, run `node scripts/test-app.mjs` for browser verification or `node scripts/capture.mjs` to refresh the four preview images.
